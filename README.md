## Project Overview
Honey Bears Bakery is a warm, homemade bakery business based in Johannesburg, South Africa. This website serves as the online home for the bakery, showcasing their products, services, and allowing customers to place enquiries and orders. The website is designed to reflect the brand's identity — warm, comforting, and welcoming — using a carefully selected colour palette of warm pink, soft cream, and warm brown tones.

This project was developed in two parts: Part 1 established the HTML structure and content, while Part 2 implements external CSS styling, responsive design, and visual enhancements to create a professional, user-friendly experience across all devices.

## Website Goals and Objectives
- To create an inviting online presence that reflects the warm, homemade nature of the bakery
- To provide clear access to product information, pricing, and services
- To enable customers to easily make enquiries and place orders through a simple form
- To deliver a fully responsive website that works seamlessly on mobile, tablet, and desktop devices
- To maintain consistent navigation and design across all pages
- To apply web development best practices including semantic HTML, external CSS, and accessibility standards

## Key Features and Functionality
- **Consistent Navigation:** Fixed navigation bar on every page with links to all sections
- **Responsive Design:** Adapts automatically to mobile, tablet, and desktop screen sizes
- **Product Display:** Clear presentation of breads, pastries, cakes, and treats with pricing
- **Enquiry Form:** Customers can submit questions, custom cake requests, and orders
- **About Page:** Information about the bakery, its story, and values
- **Contact Page:** Location details and contact information
- **Visual Design:** Warm pink, cream, and brown colour scheme; clean typography; hover effects on interactive elements
- **Optimised Images:** Responsive images that load quickly and scale correctly on all devices

## Part 1 Details
Part 1 established the core structure of the website using semantic HTML5. The following pages were created:
- **index.html** — Home page with welcome message and featured products
- **about.html** — About the bakery and its story
- **services.html** — Product listings and pricing
- **enquiries.html** — Enquiry and order form
- **contact.html** — Contact details and location information

All pages include consistent header, navigation, and footer sections. Images were optimised and organised in a dedicated `images` folder.

## Part 2 Details
Part 2 builds upon Part 1 by adding complete external CSS styling and responsive design:
- **External Stylesheet:** `styles.css` linked to all HTML pages
- **Colour Scheme:** Warm pink (#e8a8b5), soft cream (#fff9f0), warm brown (#8b5a2b) — exactly as specified in the design document
- **Typography:** Clean sans-serif fonts with clear hierarchy for headings and body text
- **Layout:** Centered content, consistent spacing, fixed header navigation, sticky footer
- **Interactive Elements:** Hover effects on navigation links and buttons; focus states on form inputs
- **Responsive Breakpoints:** 
  - Desktop: 1024px and above — horizontal navigation
  - Tablet: 768px to 1023px — centered navigation, adjusted sizing
  - Mobile: Below 768px — stacked vertical navigation, single-column layout
- **Responsive Images:** All images set to fluid width with lazy loading
- **Form Styling:** Enquiry form styled with consistent colours, borders, and interactive feedback
